# Delaro Systems homepage

This is the production-ready, dependency-free Delaro Systems homepage. It uses the approved Delaro brand system and locked logo assets with semantic HTML, responsive CSS, and a small accessible JavaScript layer.

## Run locally

Serve the directory with any static server, for example:

```sh
python3 -m http.server 4173
```

Then open `http://localhost:4173`.

## Implementation notes

- The homepage is intentionally buildless; there is no dependency installation or compile step.
- Navigation, the mobile menu, active-section state, reduced motion, reduced transparency, and increased contrast preferences are supported.
- No Client Login is shown because no functioning portal route exists.
- No external contact or legal links are published because none were verified in the supplied sources.
